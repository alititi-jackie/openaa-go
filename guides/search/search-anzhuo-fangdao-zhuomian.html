安卓手机把网站放到桌面：一键添加教程

安卓 Chrome 点菜单就能把网站添加到桌面，部分网站还支持安装成独立应用。这篇讲两种方法和区别。

安卓用户想把常用网站放桌面，很多人只知道长按浏览器图标凑合用。其实 Chrome 自带“添加到主屏幕”，点几下就行；部分网站还支持“安装应用”，装完跟原生 App 几乎没区别，点开是独立窗口、没有浏览器地址栏。这篇把两种方法一次讲清。

两种方式先分清：快捷方式 vs 安装应用

安卓 Chrome 里有两种把网站放桌面的方式，别搞混。“添加到主屏幕”是普通快捷方式：桌面多个图标，点开还是在 Chrome 里打开那个网页，跟点书签本质一样，只是少了翻书签的步骤。“安装应用”则是 PWA（渐进式网页应用）：网站做了适配，装完有独立窗口、独立任务卡片，没有浏览器地址栏和工具条，用起来跟原生 App 几乎没区别。

怎么判断网站支不支持？打开 Chrome 右上角三个点菜单：显示“安装应用”就是支持，只有“添加到主屏幕”就是普通快捷方式。两种都能用，只是体验差一档。

方法一：添加到主屏幕（通用）

所有网站通用，步骤固定：第一步，用 Chrome 打开要添加的网站；第二步，点右上角三个点菜单；第三步，点“添加到主屏幕”（部分国产手机叫“添加快捷方式”或“创建快捷方式”，是一个东西）；第四步，改个短名字，点“添加”。

图标出现在桌面，点一下直接用 Chrome 打开该网站。适合偶尔用的网站，或者网站本身不支持安装应用的情况。

方法二：安装应用（体验更好）

如果网站支持 PWA，优先用这个：第一步，用 Chrome 打开网站；第二步，点右上角三个点，选“安装应用”；第三步，在确认弹窗里点“安装”。完事，桌面多一个独立图标。

点开它是单独窗口，没有地址栏，任务切换器里也是独立卡片，启动速度还更快。像 OpenAA 搜索入口这种每天打开好几次的工具站，用“安装应用”的方式放桌面，体验最接近原生搜索 App：点图标就是搜索框，还能一键切换 Google、百度、Bing。

放桌面后怎么用得顺手

几个小习惯：名字改短，“搜索”两个字比网站全称好认得多；位置放顺手，最常用的拖到首页第一屏或底部 Dock 栏；定期清理，不用的长按图标移除就行——快捷方式选“移除”，安装应用选“卸载”，都不会影响 Chrome 里的书签。

建议把每天必用的两三个入口型网站（搜索、汇率、新闻）用“安装应用”放桌面，先打开 OpenAA 试试手感，顺手了再决定留不留。

常见问题

安装应用占手机空间吗？
几乎不占。它本质还是网页，不是真正的 App 安装包，只是多了个独立窗口的壳，体积可以忽略不计，随装随卸没负担。
菜单里只有“添加到主屏幕”，没有“安装应用”？
说明这个网站没做 PWA 适配，只能用普通快捷方式。功能上一样用，只是点开会在 Chrome 里打开网页，而不是独立窗口。
iPhone 也能这样操作吗？
iPhone 没有“安装应用”这个概念，用的是 Safari 的“添加到主屏幕”，步骤略有不同：点底部“分享”按钮 → 上滑找到“添加到主屏幕” → 改名 → 添加。具体见本站 iPhone 教程。
快捷方式点进去打不开了怎么办？
先检查网站地址有没有变，删掉旧图标重新添加一个就行。如果 Chrome 本身打不开网页，那就是网络问题，跟快捷方式无关。
